# JobFinder

JobFinder is a role-based mobile job application platform built using React Native, Expo, and Firebase. The app is designed to help job seekers easily find nearby job opportunities, apply directly through the app, and track their application status in real time.

The system supports three main user roles:

- User / Job Seeker — browse jobs, view maps, apply for jobs, and manage applications
- HR / Recruiter — post and manage jobs, review applicants, and approve or reject applications
- Administrator — manage users, control roles, and monitor the overall system

The app also includes location-based job searching, Firebase Authentication, Firestore database integration, and a clean role-based navigation system for a better user experience.

## Features

- Firebase Authentication
- Role-based login system
- Job posting and management
- Real-time application tracking
- Nearby jobs with map integration
- HR approval and rejection workflow
- Admin user management
- Responsive mobile UI using React Native and Expo
